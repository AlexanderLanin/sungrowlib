# sungrowlib

Library for communicating with Sungrow hybrid inverters (SH/SG series) via Modbus TCP and WiNet-S HTTP/WebSocket.

> **Early stage** — all development is on the [`dev`](https://github.com/AlexanderLanin/sungrowlib/tree/dev) branch.

## What's in the repo

- **Register Catalog** — machine-readable JSON database of 300+ Sungrow inverter registers, audited against official Sungrow communication protocols. Usable standalone from any language.
- **TypeScript implementation** — library + CLI, with 240+ unit/integration tests.
- **Python implementation** — placeholder, planned.
- **Conformance test suite** — language-agnostic YAML scenarios with a Modbus TCP simulator, validating any implementation against the same standard.

## Vibe-coded

This repository is an experiment in fully AI-generated development. Not a single line of code, configuration, or documentation was hand-written — 100% generated by Claude, Codex, and Copilot.

The hypothesis: vibe coding can work for non-trivial embedded communication libraries if the architecture makes correctness verifiable. The register catalog is language-agnostic JSON, the conformance tests are language-agnostic YAML, and the architecture is the same across implementations. An AI can generate an entire implementation and immediately prove it correct against the shared test suite.
